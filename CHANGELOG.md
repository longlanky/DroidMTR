# Changelog

## 1.0.0 — 2026-10-20

Initial public release.

- Root-free continuous traceroute and latency monitor for Android and Linux.
- Native ICMP ping-socket engine with automatic UDP fallback.
- IPv4 and IPv6 target support, reverse DNS, per-hop loss/latency/jitter stats,
  probe history, path strip, latency charts, and detailed hop statistics.
- Automatic saved-trace history, manual snapshots, delete/clear, and text/CSV
  sharing through the platform share sheet.
- Material 3 light/dark interface, responsive layout, custom icon and splash.
- Diagnostics for native engine loading and ICMP/UDP socket capabilities.
- Release binaries for Android (universal and per-ABI) and Linux x86_64.
